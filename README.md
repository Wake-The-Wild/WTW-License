## Applying the license to a WTW project

1. Add an unmodified copy of `LICENSE.md` to the project or release.
2. State that the project is licensed under the Wake The Wild License 1.0.
3. Include the canonical link:
   `https://github.com/Wake-The-Wild/WTW-License/blob/v1.0/LICENSE.md`
4. Adapt
   [PROJECT-NOTICE-TEMPLATE.md](templates/PROJECT-NOTICE-TEMPLATE.md) for the
   project.
5. Identify third-party files and separately licensed components clearly.

Documentation, examples, or public APIs are governed by MIT, Apache-2.0, or
another license only when the relevant material explicitly says so. WTW names,
logos, icons, and branding remain reserved unless written permission states
otherwise.
