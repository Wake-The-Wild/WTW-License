# General permission request template

Send completed requests to **wakethewild.contact@gmail.com**.

```text
Subject: WTW permission request — [PROJECT OR PURPOSE]

Your name or organization:
Contact email:
Relevant website/profile:

WTW project and version:
Requested use:
Where it will be published or operated:
Expected publication date and duration:

Is the use commercial or monetized? If yes, describe how:
Does it modify, redistribute, or include WTW files? If yes, identify them:
Will WTW names, logos, icons, or other branding be shown? If yes, describe how:

Any other relevant information:
```

Submitting a request does not grant permission. Permission exists only after
WTW provides written approval, and only for the scope and conditions stated in
that approval.
